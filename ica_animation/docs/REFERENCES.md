# Primary references

Reference links retained from the original project. Version-independent scientific discussion and official library documentation are separated from the locally executed validation in `VALIDATION.md`. The documentation links using `stable` may change with upstream releases.

**[R1] OpenStax — University Physics, Volume 1, Section 17.3: Sound Intensity.** Pressure amplitude, intensity, and spherical spreading.

https://openstax.org/books/university-physics-volume-1/pages/17-3-sound-intensity

**[R2] Aapo Hyvärinen — What is Independent Component Analysis?** Author introduction and research references.

https://www.cs.helsinki.fi/u/ahyvarin/whatisica.shtml

**[R3] scikit-learn — FastICA API.** Component counts, whitening, mixing and unmixing matrices, and convergence parameters.

https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.FastICA.html

**[R4] scikit-learn — Independent component analysis.** ICA assumptions and its distinction from PCA.

https://scikit-learn.org/stable/modules/decomposition.html#independent-component-analysis-ica

**[R5] scikit-learn — Blind source separation using FastICA.** Official signal-mixture example comparing ICA and PCA.

https://scikit-learn.org/stable/auto_examples/decomposition/plot_ica_blind_source_separation.html

**[R6] Matplotlib — FFMpegWriter.** Exporting animation frames through FFmpeg.

https://matplotlib.org/stable/api/_as_gen/matplotlib.animation.FFMpegWriter.html

The project code, numerical configuration, vector artwork, visual sequence, and tests are original. No external image assets or font files are redistributed.
