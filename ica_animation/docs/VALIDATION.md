# Validation of revision 1.1

## Executed checks

`pytest -q` completed with **35 passing tests** for revision 1.1. The captured result, `examples/test_results.txt`, is a local report excluded from version control. Run `pytest -q` to check the current checkout.

The original scientific checks cover inverse-distance amplitude and inverse-square intensity, matrix conventions, alternating source activity, two-source recovery, the three-source/two-component example, a full-rank control, deterministic estimation, and rank-one observations for identical sources.

New projection tests verify that:

- Flattening changes only the third coordinate.
- Every colored single-source observation lies on its matching mixing column.
- Vertical guides and cross-view arrows join the same sample, not an arbitrary point on the line.
- The overhead views contain identical floor points and identical mixing directions.
- The later coordinate change inverts the mixture and is distinct from floor projection.
- Time labels are hidden in the overhead view and restored correctly when seeking backwards.

Rendering tests exercise all 24 keyframes in forward and reverse order, as well as the alternative third-microphone configuration. Integration tests export an MP4 with audio and a GIF. Sonification is checked for two channels and no clipping.

The key projection, overhead, coordinate-change, recovered-direction, and final-scene stills were visually inspected.

`examples/diagnostics.json` was generated by `inspect`; scientific results were not manually substituted. The source-model code and default physical geometry are unchanged from the original project.

## Reproduce

```bash
conda env create -f conda/environment.yml
conda activate ica-animation
pytest -q
python run.py inspect --output output/diagnostics.json
python run.py stills --scene all --preset preview
python run.py render --scene all --preset preview --fps 15 --audio --output output/preview.mp4
```

The tests validate this teaching model and its exporters. They do not certify real-speech separation, acoustic realism, statistical independence of arbitrary sinusoids, or preservation of the scene-3 outcome after changing its configuration.
